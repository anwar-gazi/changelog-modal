changelog-modal-element

Universal Web Component & Markdown Sanitizer for Interactive Release Notes

1. Standalone Modal (Inline Template)

Uses inline <template> containing raw Markdown with HTML comments & AI directives. Sanitization strips them automatically.

<changelog-modal version="1.0.0" mode="standalone">
  <template>
    # Changelog
    <!-- internal -->
    ## [1.0.0] - 2026-10-06
    - First release
  </template>
</changelog-modal>

2. Standalone Modal (Dark Theme)

Supports built-in sleek dark theme mode via theme="dark".

<changelog-modal version="2.0.0" theme="dark" mode="standalone">
  ...
</changelog-modal>
